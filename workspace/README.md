# PlacementHQ — MVP Overview

PlacementHQ manages placement tracking, Scrum summaries, and mentor goals through Discord, AI, and Google Sheets.

## MVP Status

| MVP | Primary Capability | Status |
| --- | --- | --- |
| MVP-1 | Placement Tracker Sync by Discord Bot | Completed |
| MVP-2 | Scrum Updates Summary by AI | Completed |
| MVP-3 | Mentor KPI Management and Manager Approval | Completed |

## MVP-1 — Placement Tracker Sync by Discord Bot

Supporting actions:

1. Google Service connection
2. Apps Script-based APIs
3. Discord placement sync
4. Discord bot setup
5. Placement Sync page

**Result:** Placement messages are synchronized from Discord into the PlacementHQ tracker and managed Google Sheets.

## MVP-2 — Scrum Updates Summary by AI

Supporting actions:

1. Google OAuth-based file access
2. AI integration
3. Placement Workspace page
4. Weekly updates and summaries
5. Discord bot-to-user messaging

**Result:** Scrum updates are collected from Discord and converted into structured weekly AI summaries.

## MVP-3 — Mentor KPI Management and Manager Approval

Supporting actions:

1. Mentor KPI management
2. Monthly and quarterly KPI foundation
3. Mentor goal submission and manager approval
4. Manager comments and mentor resubmission
5. Approved goals in the Placement Workspace
6. Admin dashboard overview

**Result:** Mentors submit goals, managers review or comment, and approved goals appear with placement performance.

## Technology

- Next.js, React, and TypeScript
- Google Sheets, Google OAuth, and Apps Script
- Discord API and Discord Bot
- AI-assisted Scrum summarization
- Role-based access for admins, managers, and mentors
